# viewer-3d

three.js wrapper for Unitforma (plan §11.1 `libs/viewer-3d`): loads the schematic massing GLB
generated by the worker (`geometry.build_massing`), orbits around it, isolates floors and lets
the user pick units (node `extras.unit_id`). No framework binding library — a single component
owns the renderer and disposes it on destroy.

The library is consumed from source through the workspace `tsconfig.json` path mapping; the
`ng-packagr` build target is available for publishing it separately.
